# Fanamboarana APK amin'ny GitHub Actions

1. Sokafy ny tabilao **Actions** ao amin'ny repository.
2. Safidio ny workflow **Build GPS Tracker APK**.
3. Tsindrio **Run workflow** raha tsy mandeha ho azy.
4. Andraso ho vita ny asa. Raha misy hadisoana dia sokafy ny log an'ilay dingana tsy nahomby.
5. Rehefa maitso ny workflow, sokafy ilay run ary alao ny artifact **GPS-TRACKER-APK**.

Fanamarihana: mbola mila fanamarinana build sy fitsapana amin'ny finday ilay APK. Tsy midika ho voasedra amin'ny fitaovana tena izy ny hoe nahomby ny build.
